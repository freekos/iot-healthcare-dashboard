# MetaCare IoT — Metabolic Syndrome Monitoring

Seminar 3, Web Programming. One-page IoT healthcare dashboard in plain HTML + CSS.

- Live: https://freekos.github.io/iot-healthcare-dashboard/
- HTML check: https://validator.w3.org/nu/?doc=https://freekos.github.io/iot-healthcare-dashboard/
- CSS check: https://jigsaw.w3.org/css-validator/validator?uri=https://freekos.github.io/iot-healthcare-dashboard/style.css

## Files

- `index.html` — page markup
- `style.css` — styles (Grid/Flexbox, cards, table, form, hover/transition, media queries)
- `images/` — SVG icons
- `screenshots/` — desktop, mobile, W3C validation results
